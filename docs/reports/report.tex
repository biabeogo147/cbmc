\begin{abstract}
OSEK/VDX applications consist of multiple tasks, a deterministic scheduler, a ready queue,
and standardized application interfaces (APIs). If existing model checking methods for
concurrent software are applied directly to such applications, a large number of
interleavings of tasks may be checked although the running task is explicitly determined by
the scheduler. The result is an approximate verification in which unnecessary interleavings
of tasks may lead to a spurious bug. This report describes a CBMC-based bounded model
checking flow that takes the behaviours of OSEK/VDX scheduler into account and reduces
unnecessary interleavings before source-to-source instrumentation.

The first part uses OIL configuration and scheduler-related APIs so that task states, the
ready queue, and task execution order follow the OSEK/VDX model during verification. The
second part computes a manifest of candidate program points whose accesses may conflict with
globals written by the interruption code, and then inserts guarded nondeterministic calls
only at those points. On the public benchmark subset in this repository, the checked-in
evidence contains 43 measured cases: 17 same-outcome comparable cases, 10 cases audited as
\texttt{improved\_correct}, 6 \texttt{no\_injection\_false} cases, 3
\texttt{needs\_manual\_review} cases, and 7 \texttt{pending\_manual\_review} cases.
Representative public cases show that the method can remove unnecessary interleavings that
produce spurious bugs and can also expose error traces that are not reached by the stock
baseline. The added accuracy costs extra analysis and rebuild time, but it yields a more
accurate bounded model checking workflow for OSEK/VDX applications.
\end{abstract}
